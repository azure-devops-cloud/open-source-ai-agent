# Open Source AI Agent

An open-source, $0-first AI agent platform.

## Stack

- Next.js
- Vercel
- GitHub
- Supabase
- Open-source LLMs
- LangGraph (planned)
- MCP (planned)

## Roadmap

1. Next.js + Vercel foundation
2. Supabase database and authentication
3. AI provider abstraction
4. First AI agent
5. Agent tools and workflows
6. GitHub Actions automation
7. MCP server
8. ChatGPT app integration
